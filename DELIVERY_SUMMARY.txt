════════════════════════════════════════════════════════════════════════════════

📊 THREE-MODEL ARCHITECTURE:

Model 1: Inventory Lifecycle Predictor
  Algorithm: XGBoost Classifier
  Task: Predict which SKUs become slow-moving in 30 days
  Output: Probability (0-1)
  Performance: 85-90% accuracy
  Input: 9 time-series features from daily inventory data

Model 2: Price Elasticity Estimator
  Algorithm: Mixed Effects Regression + LightGBM
  Task: Estimate price sensitivity by category × store
  Output: Elasticity coefficient (e.g., -1.3)
  Performance: R² = 0.75-0.85
  Input: Historical markdown data (12-24 months)

Model 3: Markdown Optimization Engine
  Algorithm: Constrained Linear Programming (SLSQP)
  Task: Calculate profit-maximizing markdown price
  Output: Optimal discount % & price
  Performance: <100ms per SKU
  Input: Current inventory, cost, elasticity, constraints
